1

Connect Wallet

User connects MetaMask to the Sepolia testnet. The dApp reads their nonce and token balance from the blockchain.

Gas: 0 (read-only)
2

Build Actions

User defines N token transfers (recipient + amount). Actions are composed entirely in the browser — nothing touches the chain yet.

Gas: 0 (off-chain)
3

Sign via EIP-712

Each action is wrapped in a ForwardRequest struct and signed with EIP-712 typed data. MetaMask shows human-readable details. Signature binds to contract + chain.

Gas: 0 (signature only)
4

Submit to Relayer

Signed requests are sent to the relayer server via POST /api/relay. The relayer verifies each signature before queuing.

Gas: 0 (HTTP request)
5

Batch Execution

Relayer submits all requests in a single executeBatch() call. One base cost (21,000 gas) instead of N. Each sub-call verified and executed atomically.

Gas: 21K + N×13K (relayer pays)
6

Gas Reimbursement

If a GasSponsor pool is funded, the relayer claims reimbursement. 6-layer constraint system prevents abuse (per-claim, per-user, per-relayer, global, balance, pause).

Gas: Sponsored by pool

🔐 EIP-712 Signature Scheme

  • Domain separator binds to contract + chain ID
  • Typed data hash prevents cross-contract replay
  • ecrecover() verifies signer on-chain
  • MetaMask renders human-readable signing UI

🔄 Nonce-Based Replay Protection

  • Sequential nonces per user (like Ethereum itself)
  • Incremented before execution (reentrancy safe)
  • Each request is unique: (chain, contract, nonce)
  • Stale signatures automatically invalidated

📦 Trusted Forwarder Pattern

  • BatchExecutor appends real sender to calldata
  • Target contract overrides _msgSender()
  • Extracts last 20 bytes when called by forwarder
  • Compatible with any ERC-20/ERC-721 contract

💰 Sponsorship Constraint Layers

  • Per-Claim Cap: Bounds maximum reimbursement
  • Per-Relayer Daily: Prevents single-relayer drain
  • Per-User Daily: Prevents Sybil abuse
  • Global Daily + Balance + Pause: Safety nets

Trust Model

Security & Trust Guarantees

🛡️
Replay Protection

Sequential nonces + EIP-712 domain binding (chainId + contract address) make every signature globally unique.

🔒
Non-Custodial

The relayer never holds user keys or funds. It can only execute exactly what the user signed — nothing more.

🚫
Anti-Griefing

Each sub-call has its own gas limit. One failing action cannot consume the entire batch's gas budget.

🔄
Censorship Resistant

If the relayer is down, users can call executeBatch() directly on the contract, paying their own gas.

🏦
Pool Safety

6-layer constraint system on GasSponsor prevents drain attacks even with compromised relayer keys.

⏸️
Emergency Controls

Owner can pause the sponsor pool and withdraw funds instantly via emergencyWithdraw().
